# Public Demonstration Disclosure Boundary

This repository is intended to demonstrate the Prometheus system without publishing its protected implementation.

## Public

- interface screenshots;
- system workflow;
- high-level architecture;
- representative execution outcomes;
- current prototype scope;
- broader development direction;
- practical applications;
- demonstration narrative.

## Controlled

- implementation;
- proprietary equations;
- derivation;
- feature construction;
- weights and coefficients;
- internal ranking;
- detailed selection heuristics;
- private infrastructure.

## Current scope vs. future scope

The current prototype is limited to SABRE O3 and a small set of IBM Quantum processors available through the IBM Quantum Free Tier.

Planned expansion to TKET, additional compiler frameworks, additional IBM processors, Quantinuum, IonQ, and other processor technologies is **development direction**, not a claim that those integrations are already implemented in this repository.

## Review path

Public demonstration → controlled technical review → technical validation → pilot → commercial deployment.
