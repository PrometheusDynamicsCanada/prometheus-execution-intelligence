# Repository Scope

The Prometheus Dynamics public repositories publish **verifiable inputs, execution commitments, hardware job identifiers, raw measurement counts, and standalone offline verification scripts**:

### Published in Public Repositories
- Portable logical OpenQASM 2.0 circuits and exact noiseless reference distributions
- Pre-execution SHA-256 candidate and backend commitment ledgers
- IBM Quantum Job IDs and Amazon Braket Task ARNs
- Raw canonical logical measurement counts and returned hardware payloads
- Standalone Python verification and offline scoring scripts (`verify_corpus_and_schedules.py`, `score_counts.py`, `verify_ledger.py`, `validate_braket_local.py`)
